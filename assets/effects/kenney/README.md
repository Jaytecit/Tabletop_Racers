# Kenney Particle Pack textures

Source: https://kenney.nl/assets/particle-pack

Downloaded archive: https://kenney.nl/media/pages/assets/particle-pack/f8fe0f8cb8-1677578741/kenney_particle-pack.zip

The archive's `License.txt` identifies Particle Pack **1.1**, by Kenney Vleugels. It is CC0; attribution is optional. The website currently labels its release 1.0. Preserve the supplied licence rather than assuming those version labels match.

Included, unchanged, from `PNG (Transparent)/`:

- `smoke_01.png`: expanding tyre smoke, tinted dirt dust and landing puff.
- `spark_05.png`: short impact sparks.
- `light_01.png`: blue/white boost exhaust.
- `License.txt`: archive licence and contributor credits.

Smoke 04 was also inspected and retained only in `tests/baselines/vehicle_effects/texture-evaluation`. The archive is preserved in the same evidence folder. The selected soft smoke sprite remains readable at the game's pixel resolution without needing a large flipbook. Gradients, expansion curves and tyre-mark shader are locally authored. In-game Asset Credits includes Kenney's name and source.
