## Implemented

- Race messages use the menu font, ink/paper/gold palette, blue frames and consistent padding. Results include the menu pattern and focusable Retry/Main Menu buttons. Three top-centred lamps replace the numeric countdown, progressively lighting red and switching to green at the existing race start. Pause/menu/results hide them. The Recovering panel is removed entirely; recovery mechanics remain active. Course-description bounds no longer overlap the mode selector. The driver's licence lists saved race records without cup wins.
- Main-menu Setup exposes master/music/effects, mute, window size, fullscreen, pixelation and controls. Profile schema 5 stores validated settings; older profiles receive defaults. Music and effects have separate runtime audio buses. Display changes require confirmation within 15 seconds; timeout, Revert, closing Setup or Escape restores the previous display. Only confirmed display choices are saved. Window sizes are bounded by the current monitor; fullscreen uses its native mode.
- Camera modes are original chase, overhead and close chase. C cycles them while counting down/driving; right-stick click is the gamepad default. Controls allow a keyboard rebind or left-stick click. `controls.cfg` stores bindings and the selected view. Retry retains that view; cinematic staging remains separate.
