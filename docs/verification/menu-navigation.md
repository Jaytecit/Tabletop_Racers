# Directional menu navigation — 4 October 2026

> Verification record: measurements, counts, versions and failures below describe the named runs. They are not a fresh acceptance claim for the current build. See [current build](../current-build.md) and [remaining work](../implementation-checklist.md), including eight-car scope and the owner's current verification policy.

Milestone 2a implementation uses `scripts/race/menu_navigation.gd`, installed by the existing menu flow. It builds explicit focus neighbours from visible control rows after layout. Left/right stops at row ends; up/down selects the closest control to the last horizontal column, retaining that column through intermediate single-control rows. Tab order remains within the active panel. Existing slider and stat input handlers continue to adjust values without also moving focus.

The active Setup, Controls or Upgrades panel supplies the focus graph while open; otherwise the main menu or results panel does. Visibility, disabled state, focus mode and layout changes rebuild the graph. Existing modal focus suppression and close handlers restore the launch button. Native OptionButton popups and the native credits dialog keep their engine-managed navigation.
