# Source credits and notices

Keep source-specific notices with retained assets. The root `LICENSE` is a preserved CC0 source notice; it is not a blanket licence declaration for all imported models or addon code.

- Tabletop models: `assets/imported/tabletop/CREDITS.md` and each course's measurement manifest. In-game credits are assembled by `scripts/race/asset_credits.gd`.
- Other racing models: notices under `assets/imported/racing/` and the relevant measurement manifests.
- Music: `audio/music/CREDITS.md`; existing tracks are documented placeholders.
- Installed addons: their unchanged local licence/attribution files under `addons/`.
- Deferred imported packs: original licences, vendor READMEs and documentation are preserved at their original ZIP paths in `archive/source-packs/unused-imports.zip`; `manifest.json` records individual hashes.
- The original GodotRetro root README and superseded project documents are preserved in `archive/documentation-before-cleanup.zip`.

The earlier owner's CC0 statement remains historical evidence, but source-specific model metadata and bundled notices take precedence in the current inventory. This cleanup changes no source licence or attribution.
